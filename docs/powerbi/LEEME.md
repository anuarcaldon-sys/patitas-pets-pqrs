# Tablero de Power BI

Kit para construir el tablero de PATITAS-PETS. Las instrucciones paso a paso están en [`../08_guia_power_bi.md`](../08_guia_power_bi.md).

| Archivo | Contenido |
|---|---|
| `tema_patitas_pets.json` | Tema de colores (Vista → Temas → Examinar temas) |
| `consulta_power_query.pq` | Consulta que carga la base consolidada desde GitHub |
| `medidas_dax.dax` | Medidas y columna calculada del tablero |
| `valores_control.md` | Cifras esperadas para verificar el tablero |

Cuando el tablero esté listo, guarde aquí:

- `PATITAS-PETS_dashboard.pbix`: archivo de Power BI Desktop.
- `PATITAS-PETS_dashboard.pdf`: copia en PDF para consultarlo sin Power BI.
